# Roadmap

Planned improvements, in no fixed order. Want to help with one? See [CONTRIBUTING.md](../CONTRIBUTING.md), and comment on the matching issue (or open one) before you start so work isn't duplicated.

## GitHub stats cards

Optional cards showing GitHub activity, such as total stars, commits and top languages, added as a section like the snake and the views counter: a switch, sensible defaults, and a place in the section order.

## Profile import and export

Save the whole profile as a JSON file and load it again later, so you can:

- move your work to another device or browser
- keep a backup that survives clearing browser data
- share a starting point with a friend

## Colour options

Choose colours instead of the fixed defaults:

- **Contribution snake:** snake and grid colours (Platane/snk supports custom palettes).
- **Profile views counter:** the badge colour.

## Already shipped

- Editor and landing page in a single page
- Contribution snake with a ready-made workflow
- Profile views counter
- Section on/off, renaming and reordering
- Themed reset confirmation
- Automatic deployment to GitHub Pages
